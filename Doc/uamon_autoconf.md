# Автоконфигурирование карт по мап-серверам (uamon-autoconf)

Раз в месяц перераспределяет локации по `confN/maps_athena.conf`, балансируя нагрузку по пикам из
мониторинга (`scripts/cron/uamon-autoconf.sh`). Рестарт в 02:00 применяет новые списки.

## Алгоритм
1. **Число чанков N** = фактически запускаемых серверов = `min(#confN, ⌊threads/2⌋−1, 30)` (та же
   формула, что у лаунчера `ua-mapcount.sh`). Если `#confN` больше — **предупреждение** и cap до N
   (иначе карты ушли бы на сервера, которые не стартуют → недоступные локации).
2. **Мастер-список** = активные `map:` из `conf/maps_athena.conf` (комментированные игнорятся). Этот
   файл **только читается, никогда не перезаписывается**.
3. **Пики** = `MAX(players_max)` по каждой карте из `stat_hour` за последние **6 недель** (настр.
   `AUTOCONF_WEEKS`), сортировка по убыванию.
4. **Фаза 1** — пары (самая нагруженная + самая ненагруженная) в текущий чанк, round-robin по чанкам;
   обе исключаются. Нечётный остаток → одиночная карта.
5. **Фаза 2** — карты мастера без статистики (никто не заходил) раскидываются по одной round-robin
   (продолжая ту же ротацию) → ровно по количеству.
6. **Валидация инварианта eAthena**: каждая карта мастера ровно в одном чанке, без дублей между
   чанками. При нарушении — **аборт, конфиги не трогаются**.
7. Запись **атомарно** (`tmp`→`mv`) с **таймстамп-бэкапом** (хранятся последние 6).

Пустая БД (мониторинг <6 недель) → всё уходит в Фазу 2 (ровный сплит по количеству).

## Файлы
- Читает: `$AUTOCONF_ROOT/conf/maps_athena.conf` (мастер) + `stat_hour` (Mongo).
- Пишет: `$AUTOCONF_ROOT/confN/maps_athena.conf` (`map: имя` строки, автоген-заголовок).
- `AUTOCONF_ROOT` деф. `/opt/uathena`.

**Важно:** `confN/map_athena.conf` каждого инстанса должен импортировать `confN/maps_athena.conf`
(а НЕ `conf/maps_athena.conf`), иначе инстанс загрузит ВСЕ карты → дубли. Скрипт **предупреждает**,
если видит импорт мастера.

## Крон (1-го числа каждого месяца)
```
0 1 1 * *   uamon-autoconf.sh          # 01:00 пересборка списков карт
0 2 1 * *   systemctl restart uAmap.service   # 02:00 применение (рестарт супервизора)
0 4 1 * *   uamon-cleanup.sh           # 04:00 чистка статистики
```
Рестарт кикнет онлайн — на 02:00 приемлемо. Если у тебя свой скрипт рестартов — замени строку.

## Проверка / тюнинг
- `AUTOCONF_DRYRUN=1 uamon-autoconf.sh` — печатает план (раскладку по чанкам), **ничего не пишет**.
- `AUTOCONF_PEAKS_FILE=<файл>` — взять пики из файла (`map peak` построчно) вместо Mongo (тест).
- `AUTOCONF_WEEKS` — окно статистики (деф. 6).

## Проверено
Распределение (пары+round-robin+leftovers), инвариант (покрытие/без дублей), мастер нетронут,
атомарная запись+бэкап+прунинг, cap по CPU с предупреждением, фолбэк на пустой БД — все на моках OK.
Живой Mongo-запрос — на боксе (mongosh).
