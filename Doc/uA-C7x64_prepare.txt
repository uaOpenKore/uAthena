// Installation CentOS 7 x64 with building custom vanilla kernel 5.4+
// DOC updated 2024/11/25
// Recommended: CPU: 3, RAM: 3Gb, HDD: 30Gb, without swap part (file 1G)
// Minimum: 2/2/25/2
// Max: 4/4/30/1
// qemu: generic, partitions: standart ext4

0. Download the installation image and install it on a virtual machine: VirtualBox, Qemu or another:
https://vault.centos.org/7.9.2009/isos/x86_64/CentOS-7-x86_64-Minimal-2207-02.iso

0.1. Removing broken repositories:
rm -f /etc/yum.repos.d/*

0.2. Creating the correct list of repositories:
vi /etc/yum.repos.d/my.repo

1.1. Removing harmful glamour:
dnf -y remove plymouth* abrt* dracut-config-rescue
rm -f /boot/*rescue* /boot/loader/entries/*rescue*

2. Disabling all interference:
systemctl disable firewalld
~ SELINUX=disabled:
vi /etc/selinux/config

3. Setting DNF:
echo "deltarpm=0" >>/etc/dnf.conf
echo "max_parallel_downloads=20" >>/etc/dnf.conf
echo "fastestmirror=1" >>/etc/dnf.conf

4. Сorrect creation of swap:
dd if=/dev/zero of=/swapfile bs=1MB count=1024
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo "/swapfile swap swap defaults 0 0" >>/etc/fstab
echo "vm.swappiness = 5" >>/etc/sysctl.conf

5. Updating the system and cleaning up the rudiments:
dnf update -y
rm -f /etc/yum.repos.d/C*
reboot
dnf -y remove kernel*3.10* kernel*debug*
yum clean all

6. Installation of working packages:
dnf -y groupinstall "Development Tools"
dnf -y install mysql mysql-community-devel mysql-community-server gcc make perl kernel-devel kernel-headers bzip2 pcre-devel git zlib-devel glibc-devel ncurses-devel hmaccalc binutils-devel elfutils-libelf-devel bc openssl-devel rpm-build rpmdevtools dnf-auto* attr texinfo libacl-devel

7. Installing a guest addon, Qemu example:
dnf install qemu-guest-agent  -y
systemctl enable qemu-guest-agent
systemctl start qemu-guest-agent

~~~~~~~~~
Example of compilation a custom kernel 5.4.286(*). This is necessary for the correct operation of hardware released newer than the current kernel (uname -a) (5.15.80-200.el7.x86_64)
~~~~~~~~~

8. Preparing the system:
rpmdev-setuptree
dnf -y install bpftool kernel-cross-headers kernel-modules-extra kernel-modules-internal perf perl-generators perl-interpreter python3-perf mock python2-koj* python3-devel dnf-plugins-core
useradd mockbuild
useradd mock
usermod -G mock mockbuild

9. You will need TAR 1.28+, so we will build 1.30 via SPEK and non-root user:
useradd pix
su pix
cd
rpmdev-setuptree
curl -O https://vault.centos.org/8.0.1905/BaseOS/Source/SPackages/tar-1.30-4.el8.src.rpm
sudo dnf builddep /home/pix/tar-1.30-4.el8.src.rpm -y
rpm -i /home/pix/tar-1.30-4.el8.src.rpm
rpmbuild -ba /home/pix/rpmbuild/SPECS/tar.spec
exit
dnf -y install /home/pix/rpmbuild/RPMS/x86_64/tar-1.30-4.el7.x86_64.rpm

10. Now let's work directly on the kernel! Download, unpack and Launch configurator:
curl -O https://cdn.kernel.org/pub/linux/kernel/v5.x/linux-5.4.286.tar.xz
tar -xf ~/linux-5.4.286.tar.xz -C /usr/src/kernels/
cd /usr/src/kernels/linux-5.4.286
make menuconfig
(or) make nconfig

10.1. Install and add what is need:
General setup >  Local version : (clear)
General setup >  Build ID Salt : (clear)
General setup > Compiler optimization level (Optimize for performance -> (-Os))
64-bit kernel : ENABLE
Processor type and features > Processor family :
    AMD: Opteron/Athlon64/Hammer/K8
    INTEL: Core 2/newer Xeon
    Universal(i686): Generic-x86-64
Processor type and features > Generic x86 support : ENABLE
Processor type and features > AMD microcode loading support : ENABLE

10.2. DISABLE ERRORS (modules):
(drivers/dma/dw-edma/dw-edma-v0-core.o) DEVICE DRIVERS->DMA Engine support->Synopsys DesignWare eDMA PCIe driver && Synopsys DesignWare eDMA controller driver
(drivers/fpga/dfl.o) DEVICE DRIVERS->FPGA Configuration Framework->FPGA Device Feature List (DFL) support
(drivers/gpu/drm/i915/gt/intel_lrc.o) DEVICE DRIVERS->Graphics support->Intel 8xx/9xx/G3x/G4x/HD Graphics
(drivers/i2c/i2c-slave-eeprom.o) DEVICE DRIVERS->I2C support->I2C eeprom slave driver
(drivers/iio/adc/ad7124.o) DEVICE DRIVERS->Industrial I/O support->Analog to digital converters->Analog Devices AD7124 and similar sigma-delta ADCs driver
(drivers/iio/chemical/bme680_core.o) DEVICE DRIVERS->Industrial I/O support->Chemical Sensors->Bosch Sensortec BME680 sensor driver
(drivers/iio/humidity/hts221_core.o) DEVICE DRIVERS->Industrial I/O support->Humidity sensors->STMicroelectronics HTS221 sensor Driver
(drivers/iio/imu/st_lsm6dsx/st_lsm6dsx_core.o) DEVICE DRIVERS->Industrial I/O support->Inertial measurement units->ST_LSM6DSx driver for STM 6-axis IMU MEMS sensors
(drivers/iio/light/vcnl4035.o) DEVICE DRIVERS->Industrial I/O support->Light sensors->VCNL4035 combined ALS and proximity sensor
(drivers/mmc/host/sdhci.o) DEVICE DRIVERS->MMC/SD/SDIO card support->Secure Digital Host Controller Interface support
(drivers/net/ethernet/netronome/nfp/nfpcore/nfp_nsp.o) Device Drivers > Network device support > Ethernet driver support->Netronome(R) devices
(net/mac80211/main.o) Networking support > Wireless -> Generic IEEE 802.11 Networking Stack (mac80211)
(drivers/platform/x86/intel_pmc_core.o) Device Drivers > X86 Platform Specific Device Drivers -> Intel PMC Core driver
(drivers/net/phy/adin.o) Device Drivers > Network device support > PHY Device support and infrastructure->Analog Devices Industrial Ethernet PHYs
(drivers/net/phy/aquantia_main.o) Device Drivers > Network device support > PHY Device support and infrastructure->Aquantia PHYs
(drivers/net/phy/marvell.o) Device Drivers > Network device support > PHY Device support and infrastructure->Marvell PHYs
(drivers/net/wireless/intel/iwlwifi/pcie/rx.o) Device Drivers > Network device support > Wireless LAN -> Intel Wireless WiFi Next Gen AGN - Wireless-N/Advanced-N/Ultimate-N (iwlwifi)
(drivers/scsi/ufs/ufshcd.o) Device Drivers > SCSI device support > SCSI low-level drivers -> Universal Flash Storage Controller Driver Core
(drivers/infiniband/hw/hfi1/pcie.o) Device Drivers > InfiniBand support > Intel OPA Gen1 support

10.3. After configuring and saving, we start the compilation. If errors appear, we return to the configuration stage, disable the erroneous module and start the compilation again:
make rpm-pkg -j4

10.4. Installing new kernel packages:
dnf -y install ~/rpmbuild/RPMS/x86_64/kernel*

10.5. Reboot in 5.4 (U can edit default in /boot/grub2/grub.conf & /etc/default/grub):
grub2-mkconfig -o /boot/grub2/grub.cfg
reboot

10.6. You may need to update the Guest Additions for the new kernel.
10.7. I recommend leaving the kernel installed via the package manager, as it may hold a number of necessary packages in the system.
