# 1. uAthena Ideology

- uAthena idealizes the development of Ragnarok Online Episode 10.3 (Noghalt ~ The Abyss Lake, The Tower of Thanatos (2006)) as the foundational base for game formation. The commit `22841458a136811b550d3efcd1e3dffe52358505` from 2006-04-06 of [eAthena](https://github.com/eathena/eathena) serves as the basis upon which uAthena continues to evolve in both codebase and setting.

- uAthena continues to support and maintain code in C language. All further changes and improvements are also planned to be implemented in C.

- uAthena’s code evolution may include adaptation to new ideas and concepts, as well as allow for structural and conceptual changes, including backporting in original and/or other forms from later eAthena commits.

- The setting of Ragnarok Online, implemented through uAthena, allows content expansion by partial and/or full backporting from eAthena.

- uAthena continues to operate under the GNU/GPL version 2 license (June 1991) based on eAthena commit `22841458a136811b550d3efcd1e3dffe52358505` from 2006-04-06 (forking point). The license text is available in the `LICENСE` file.

    If a backport involves code and/or content distributed under a different license, that segment will adhere to the terms of its respective license. Should the license of a code segment override the main code license, this action unconditionally applies to the corresponding code/content segment.

    On September 9, 2010, eAthena switched to GNU/GPL version 3 (June 29, 2007) — the license text is also provided in the `LICENSE` file. Therefore, the jurisdiction of GNU/GPLv2 can be replaced by GNU/GPLv3. Additionally, uAthena is not limited to backporting code/content from other projects, such as [rAthena](https://github.com/rathena/rathena) (GNU/GPLv3), [Hercules](https://github.com/HerculesWS/Hercules) (GNU/GPLv3), and/or other similar projects.

- uAthena respects and preserves the authorship of the original and backported code/content. An "Authors" section is created in this `README.md` file. If you know of a lost author’s name or nickname for code/content/segment, please contact any member of the uAthena project to have the name added to the appropriate list.


# 2. uAthena Goals

1. Maintaining game balance in its base form or ideologically close to it.
2. Expanding the Ragnarok Online setting.
3. Enhancing playability.


# 3. uAthena Objectives

1. uAthena aims to simplify the software code:

- Minimizing supported OS to Linux only, therefore, the instructions for setting up the virtual environment for uAthena are provided here: [Doc/uA-OS_prepare.txt](https://github.com/uaOpenKore/uAthena/blob/main/Doc/uA-OS_prepare.txt)
- uAthena may potentially discontinue the TXT version of the database

2. To enhance playability, uAthena aims to implement better software algorithms and utilize all technical capabilities of the OS and hardware

3. The uAthena developers manage current tasks in the `TODO`.txt file
