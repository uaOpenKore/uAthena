# Umbalian Language Quest

## Overview
Retrieve three reference items for Fabius to learn the Umbalian language.

## NPCs and Coordinates
- **Fabius** — Yuno (`yuno.gat`) **157,366**
- **Mason** — Prontera (`prontera.gat`) **145,290**
- **Mojo** — Aldebaran (`aldebaran.gat`) **153,212**
- **Marie** — Amatsu (`amatsu.gat`) **267,189**

## Required Items
- **Old Magic Book** x1 (item 1006)
- **Torn Spell Book** x1 (item 7117)
- **Torn Scroll** x1 (item 7118)

## Step-by-step
1. Talk to **Fabius** in Yuno (**157,366**) to start the quest.
2. Visit **Mason** in Prontera (**145,290**) and answer his location question correctly to get **Torn Spell Book**.
3. Visit **Mojo** in Aldebaran (**153,212**) to progress that subtask (he hints about the lost book).
4. Visit **Marie** in Amatsu (**267,189**) and trade **Poring Egg** + **Pet Incubator** to get **Torn Scroll**.
5. Obtain the **Old Magic Book** (from monsters or market).
6. Return to **Fabius** with all three items to learn the Umbalian language.

## Reward / Result
- **Umbalian Language learned** (quest flag `event_umbala` updated)
