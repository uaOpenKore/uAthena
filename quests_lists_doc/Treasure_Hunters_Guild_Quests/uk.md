# Квести Гільдії Мисливців за Скарбами

## Огляд
Вступіть до гільдії в Юно, беріть випадкові завдання й отримуйте жетони для магазину.

## NPC та координати
- **Guild Leader (Keegan)** — Внутрішній Юно (`yuno_in01.gat`) **124,164**
- **Quest Manager** — Внутрішній Юно (`yuno_in01.gat`) **112,151**
- **Treasure Token Shop** — Внутрішній Юно (`yuno_in01.gat`) **150,152** (з THQS_TTShop)

## Вимоги для вступу
- **25 000 zeny**

## Кроки (вступ)
1. Ідіть до **Keegan** у **yuno_in01.gat 124,164**.
2. Оберіть **«I want to be a Treasure Hunter»** та сплатіть **25 000 zeny**.
3. Після вступу доступні квести й магазин.

## Кроки (квести)
1. Поговоріть з **Quest Manager** у **112,151**.
2. Візьміть випадковий квест (не можна брати кілька одночасно, є затримка між взяттями).
3. Виконуйте вказівки цільового NPC на потрібній карті.
4. Поверніться до **Quest Manager** та отримайте **Treasure Tokens**.

## Примітки
- Пул завдань включає доставку, полювання та пошукові місії по всьому світу.
- Нагорода — **Treasure Hunter Tokens** для обміну у магазині гільдії.

## Результат
- Доступ до повторюваних квестів гільдії та магазину жетонів.
