# Bandit Beard Quest

## Overview
Multi-step quest across Umbala, Izlude, Aldebaran, and Alberta to craft the Bandit Beard.

## NPCs and Coordinates
- **Bearded Man** — Umbala (`umbala.gat`) **126,129**
- **Master Tailor** — Izlude Interior (`izlude_in.gat`) **123,175**
- **Karfa Clerk** — Aldebaran Interior (`aldeba_in.gat`) **70,179**
- **Thread Merchant** — Alberta (`alberta.gat`) **65,123**

## Requirements (final hand-in)
- **Thread** x1 (item 7200)
- **Elastic Band** x1 (item 919)
- **Black Dyestuff** x1 (item 983)
- **Grandpa Beard** x1 (item 2241)
- **Sticky Mucus** x100 (item 938)
- **Counteragent** x1 (item 973)
- **2 Carat Diamond** x1 (item 731)

## Step-by-step
1. Start with **Bearded Man** in Umbala (**126,129**) and accept the beard quest.
2. Go to **Master Tailor** in Izlude Interior (**123,175**) for the thread lead.
3. Talk to **Karfa Clerk** in Aldebaran Interior (**70,179**) to learn about the attacked shipment.
4. Find the **Thread Merchant** in Alberta (**65,123**) and agree to help.
5. Defeat the spawned **Thief Bugs** and talk to the merchant again to obtain **Thread**.
6. Return to **Bearded Man** with all required items and craft the **Bandit Beard**.

## Reward
- **Bandit Beard** x1 (item 2237)
