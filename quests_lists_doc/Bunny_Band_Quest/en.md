# Bunny Band Quest

## Overview
Event-style quest to craft a Bunny Band by turning in a small set of items to the Kafra Corp. representative.

## NPCs and Coordinates
- **Kafra Corp. Rep.** — Alberta (`alberta`) **23,232**

## Requirements
- **Feather** x100 (item 949)
- **Four Leaf Clover** x1 (item 706)
- **Pearl** x1 (item 722)
- **Kitty Band** x1 (item 2213)

## Step-by-step
1. Go to **Alberta 23,232** and talk to **Kafra Corp. Rep.**
2. Select **“Join”** to register for the event quest.
3. Collect all required items.
4. Talk to the same NPC again (no special menu needed).
5. If you have all items, they are removed and you receive the **Bunny Band**.

## Reward
- **Bunny Band** x1 (item 2214)
