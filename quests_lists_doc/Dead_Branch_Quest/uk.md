# Квест «Dead Branch»

## Огляд
Обмін дерев’яних матеріалів на Dead Branch з невеликим шансом Bloody Branch.

## NPC та координати
- **Mister Mobry** — Ніфльхейм (`niflheim.gat`) **204,179**

## Вимоги
- **Log** x3 (item 7201)
- **Wooden Heart** x1 (item 7189)
- **Trunk** x5 (item 1019)
- **Wooden Gnarl** x1 (item 7222)

## Кроки
1. Поговоріть з **Mister Mobry** у Ніфльхеймі (**204,179**).
2. Оберіть **«Make me a Dead Branch!»**.
3. Передайте всі матеріали.
4. Отримаєте **Dead Branch** (рідко — **Bloody Branch**).

## Нагорода
- **Dead Branch** x1 (item 604), з шансом 0,1% на **Bloody Branch** (item 12103)
