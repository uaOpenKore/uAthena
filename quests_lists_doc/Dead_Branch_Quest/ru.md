# Квест «Dead Branch»

## Обзор
Обмен древесных материалов на Dead Branch с небольшой вероятностью Bloody Branch.

## NPC и координаты
- **Mister Mobry** — Нифльхейм (`niflheim.gat`) **204,179**

## Требования
- **Log** x3 (item 7201)
- **Wooden Heart** x1 (item 7189)
- **Trunk** x5 (item 1019)
- **Wooden Gnarl** x1 (item 7222)

## Пошагово
1. Поговорите с **Mister Mobry** в Нифльхейме (**204,179**).
2. Выберите **«Make me a Dead Branch!»**.
3. Передайте все материалы.
4. Получите **Dead Branch** (редко — **Bloody Branch**).

## Награда
- **Dead Branch** x1 (item 604), с шансом 0,1% на **Bloody Branch** (item 12103)
