# Квест «Thanatos Tower Statues»

## Обзор
Головоломка со статуями/духами: говорить с NPC в правильном порядке, чтобы открыть следующие этажи башни.

## NPC и координаты (ключевые точки)
- **Statue** — `tha_t08.gat` **69,106** (вступительный текст)
- **Thalos** — `tha_t09.gat` **17,158**
- **Mediane** — `tha_t09.gat` **84,99** (варп на `tha_t10`)
- **Melkor** — `tha_t10.gat` **130,159**
- **Zebrus** — `tha_t10.gat` **160,98**
- **Veriaelle** — `tha_t10.gat` **99,97** (варп на `tha_t11`)
- **Throtre** — `tha_t11.gat` **16,85**
- **Klermaz** — `tha_t11.gat` **85,16**
- **Mihane** — `tha_t11.gat` **16,16**
- **Seranes** — `tha_t11.gat` **85,85** (варп на `tha_t12`)

## Пошагово
1. Прочитайте **Statue** на `tha_t08 69,106`.
2. На `tha_t09` поговорите сначала с **Thalos**, затем с **Mediane**, чтобы получить варп на `tha_t10`.
3. На `tha_t10` поговорите **Melkor** → **Zebrus** → **Veriaelle** по порядку, чтобы открыть варп на `tha_t11`.
4. На `tha_t11` поговорите **Throtre** → **Klermaz** → **Mihane** → **Seranes** по порядку, чтобы открыть варп на `tha_t12`.
5. На следующих этажах следуйте порядку духов — неправильная последовательность сбрасывает прогресс.

## Результат
- Доступ к более высоким этажам Thanatos Tower через варпы статуй.
